# Admin Dashboard

A modern and responsive Admin Dashboard built with React, CoreUI, and Redux.

## Features

- 📊 Dashboard analytics
- 👥 User management
- 📈 Charts and statistics
- 🧩 Reusable UI components
- 📝 Forms
- 🔐 Authentication pages
- 🌙 Dark-themed interface
- 📱 Responsive design
- ⚡ Fast development with Vite

## Tech Stack

- React
- Redux
- CoreUI
- JavaScript
- Vite
- Bootstrap
